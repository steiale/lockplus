# Fable app-side security review (2026-10-26). Fix ALL.

## High
### H1: the master key is regenerated over existing sealed files; uninstall deletes the key while keeping profiles
- **Where:**
  - `App/Stores/ProfileRepository.swift:36-43`: `loadKeys` creates a new key when the item is missing or the wrong size. `list()` then quarantines every profile as "tampered".
  - `AppActions.swift:459-460`: the Uninstaller deletes `payload-key/v1` before the cancellable deactivate and regardless of `deleteProfilesAndHistory`. The copy at `ImportSheets.swift:240` promises the profiles survive.
- **Fix:**
  - **Key missing:** when the key is missing but sealed or metadata files exist, enter the §6.8 `.locked` state (names from unverified metadata; Re-import / Remove) and create no key.
  - **Wrong size:** throw `.secretStoreUnavailable`; never overwrite.
  - **Uninstall:** delete the master key only together with the profile files, and only after deactivation succeeds. Fix the copy.
  - **Tests:** sealed files + no key → locked, nothing moved; uninstall-without-delete then reinstall → profiles load.

## Medium
- **M1** Preview/test mode is reachable in Release (`AppEnvironment.swift:15-17` honours `LP_PREVIEW_MODE` and `defaults LPPreviewMode`; `AppDelegate.swift:13,56-60` honours the XCTest env), so the shipped app can show fake "Protected". **Fix:** `#if DEBUG` only; Release always `.live`; compile `PreviewBackends`/`PreviewUpdater` out of Release; add a UnitRelease test.
- **M2** `AtomicFile.write` chmods the user-chosen export directory to 0700 (`AppDataStore.swift:27-34`; callers `AppActions:109,133,403`, `DiagnosticsExporter:177`). **Fix:**
  - split `writeAppFile` (0700 dir) from `writeUserFile` (`O_CREAT|O_EXCL|O_NOFOLLOW` temp, 0600, rename, no dir mutation);
  - export must report failures.
- **M3** `verify.sh static` doesn't refuse the Sparkle placeholders. **Fix:** fail unless `SUFeedURL` is https with a non-.invalid host and `SUPublicEDKey` decodes to 32 bytes; share the rule with `isConfigured`.
- **M4** Sparkle reads `SUFeedURL` and the auto-update booleans from user defaults first (`SUHost.m:395-403`, `SPUUpdater.m:1155,1167`). **Fix:**
  - delegate `feedURLString(for:)` returns the Info.plist value;
  - `clearFeedURLFromUserDefaults()` at start;
  - set `automaticallyDownloadsUpdates = false` and `automaticallyChecksForUpdates = true` explicitly after `startUpdater()`.

## Low
- **L1** Profile names are logged `.public` (`ProfilesStore.swift:78-82` + call sites). **Fix:** log the id prefix publicly and the name `.private(mask: .hash)`.
- **L2 (UI)** The editor masking copy guard only covers `writeSelection`; the find bar searches masked text; Share/Services/Look Up bypass it. **Fix:** refuse `validRequestor(forSendType:)` and the sharing picker over secret lines while masked, and gate the find bar.
- **L3** `refreshCredentialFacts` loads full credential records on every `load()`. **Fix:** keep the facts non-secret (attributes-only); read secrets only in show/change/provision.
- **L4** ProcessRunner stalls on output above `maxBytes`. **Fix:** drain to EOF and keep the first N bytes.
- **L5** The instance lock is advisory; a second instance proceeds. **Fix:** after the retries, show "already running" and quit.
- **L6** Diagnostics `keep` applies to the whole bundle; `profiles.json` has raw DNS servers. **Fix:** scope `keep` to `routes.txt`/`dns.txt`.
- **L7** Crash-report read has a symlink TOCTOU (`DiagnosticsExporter.swift:45-54`). **Fix:** `open(O_NOFOLLOW)` + `fstat`.
- **L8 (UI)** The server prompt text is rendered verbatim up to 1 KiB (`AuthPromptView.swift:226-237`). **Fix:** strip C0/C1 and bidi controls, collapse newlines, cap at ~256.

## Nits
- `ProfileRepository.swift:145-146`: use `AES.GCM.open(inPlace:)` on 27 (`#available`); zero the Data.
- `ProfilesStore.swift:139,171,348`: hash the raw buffer; send Data, not String.
- `AppActions.swift:131`: names starting with "." become hidden files. **Fix:** use the sanitizer.
- `LegacyAppDetector.swift:134-170`: `lstat` the socket and require `st_uid == getuid()`.
- `migration.json` stores the absolute Go path. **Fix:** store it relative to the home directory.
- `Keychain.swift:81`: master key as `kSecClassKey` if feasible.
