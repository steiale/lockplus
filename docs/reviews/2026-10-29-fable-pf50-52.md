# Fable review: cfeee49..a06412a (PF 50–53, uninstall fix), 2026-10-29. Fix ALL.

1. **MEDIUM: PF 52 restarts on a sticky `pluginFailed`** (`ConnectionStore.swift:175-181`). A clean on-demand Disconnect (trusted SSID), a stop from System Settings/scutil, or a stop by another user after an earlier crash is restarted against the user's intent.
   - **Fix:** gate on a fresh crash signal: XPC `.reconnecting(since)` seen within ~10 s before this `.disconnected` (or since the last `.connected`), plus `wasConnected`. Otherwise ignore the 12 for both PF 52 and PF 53.
   - **Test:** sticky 12 + clean disconnect → no restart.
2. **LOW: PF 50 push can replace the attempt carrying a one-shot answer** (`TunnelController.swift:1211-1244`, `inStartAuth` 399-430, `runStarting` 317-318). The OTP is lost, and a rejection counts toward the hard latch.
   - **Fix:** `inStartAuth` clears `heldReason`/`heldError`. `pushEndpoints` refuses `.notHeld` when `broker.live != nil` or the in-flight attempt carries an answer (`Session.answerAttempt`).
3. **LOW: PF 50 push bypasses a `.backoff` latch's `notBefore`** (`TunnelController.swift:237-242`, `:1227`).
   - **Fix:** compare against the effective map (cache ∪ options ∪ pushed), or require `now >= notBefore` unless the IPs differ from the cache.
4. **LOW/INFO: no push budget; the cache grows with arbitrary hostnames** (`:1229-1244`, `:352-354`).
   - **Fix:** cache only hostnames the profile references, and cap `endpointHosts[key]` at 8.
   - **Fix:** a per-session push budget (10 → `.unchanged`).
5. **LOW/INFO: proxy credentials follow an unauthenticated IP** (`OVPNRemoteRewriter.swift:101-112`, `OpenVPNAdapter.swift:168-172`).
   - **Fix:** document in §9.3/§20; no code change.
6. **LOW: `endAttachedSheets` can spin** (`SystemHooks.swift:118-126`).
   - **Fix:** one bounded loop (cap 8), and log when the cap is hit.
