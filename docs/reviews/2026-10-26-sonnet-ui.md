# Sonnet UI review: App/UI, Tools/ui, UI tests (2026-10-26)

The full findings are in the lead session's report. Summary list (fix ALL):

## High
- **H1** ⌘⌫ "Delete…" menu item deletes without confirmation (`SceneSupport.swift:~149`). It also collides with the ⌘⌫ text-editing key.
- **H2** "Show in menu bar" OFF never hides the item (`MenuBarController.swift:98`). Warn before hiding the only UI.
- **H3** The editor can draw a PrivateKey unmasked while the analysis is stale; the fragment `lineStartOffset` is captured once (`ConfigTextView.swift:119-135`). Mask fail-closed; add a pixel test with an insert above a key line.
- **H4** VoiceOver / the AX API read the masked key (`SecretAwareTextView` lacks `accessibilityValue` / `accessibilityString(for:)` overrides).

## Medium
- **M5** Standard menu items go stale while the menu is open; rebuild them on the header's observation change.
- **M6** Menu header countdowns freeze (rows 10 and 2); read a 1 Hz tick.
- **M7** Profile notes can be lost on profile switch (`ProfileDetailView.swift:126-134`).
- **M8** "Show Logs" in the error sheet only dismisses (`ProtectionHero.swift:251`).
- **M9** Six sheets and two alerts on one view with no coordinator; auth can fail to present. Use one `activeSheet` with a priority queue.
- **M10** The status-item accessibility label is wrong for the blocked non-retryable rows; `ProfileRow` hides subtitles from VoiceOver.
- **M11** Activity summary says "This week" for every range; the filter matches profile names instead of IDs.
- **M12** Editor Revert has no confirmation and clears undo.
- **M13** The editor close-alert Save doesn't close the window and beeps on errors; quitting with dirty editors loses edits.
- **M14** The gutter lays out from the top of the document; whole-document relayout on each analysis pass; `referenceKey` splits the whole text on every caret move.
- **M15** ⌘A ⌘C over a masked key only beeps.
- **M16** The uninstall sheet's default button is the destructive one.
- **M17** Localization:
  - No translations exist. **Decision: ship English + German in v2.0; remove ko/ja from `knownRegions`.**
  - Fix the German-length risks: the fixed 600×480 onboarding sheet, the 300 pt header, `lineLimit(1)` rows, the 150 pt column.
  - The `reason()` fragment is reused after ":" and "because"; split it.
  - Hard-coded "s" and "KB/s" units: use Measurement/Duration formatters.
  - Meaningless inflection on `^[%lld unsupported]`.
- **M18** Dark-mode sidebar: the selected row is invisible (`main-blocked-dark.png`). Check it live, not only offscreen. Probably a forced `foregroundStyle` against the selection.
